# Waterlogging Detection System

A simple Python application for waterlogging detection using a trained YOLO model.

## Setup & Usage

1. Put `best.pt` inside `weights/`:
   ```text
   weights/best.pt
   ```

2. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```

3. Run the application:
   ```powershell
   python main.py
   ```

4. Enter an image or video path when prompted. Results will be saved in `outputs/` and opened automatically.
